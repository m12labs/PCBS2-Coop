# Phase 13 remote avatar model research

Reviewed November 8, 2026 for PCBS2 Coop 0.57. The reference image sets the style direction for an original rounded biped with a simple silhouette. The shortlist excludes itch.io models and uses publisher pages or release records. Rights are evaluated for both the public source repository and the downloadable mod. Asset import, deformation and in-game appearance remain to be tested.

## Selected replacement

The owner chose **GDQuest Mannequiny v0.2.0**. The adapted model, rebuild steps and CC BY 4.0 attribution are recorded in the current avatar documentation. [Current avatar](../playermodel.md#current-avatar) · [GDQuest v0.2.0 release](https://github.com/gdquest-demos/godot-3d-mannequin/releases/tag/v0.2.0)

## Original model option

An original matte mannequin in Blender would have a round head, soft shoulders and hips, distinct feet and subtle hand shapes. A small visor or chest panel would give it a clear front and a place to put the existing player tint. The old avatar's segmented mesh and missing clavicles forced mesh cleanup and a rest-pose correction. An original skeleton could be designed around the proportions and contact poses the workshop needs. [Current avatar import record](../playermodel.md#44-result-october-26-2026-shyr-base-character)

## Original model build path

1. Make a symmetrical neutral-pose mesh from rounded forms with deliberate edge loops at elbows, knees, shoulders and hips. Prototype with hand-shaped geometry and an original skinned armature. A small Blender Python generator can make proportions, naming and weights reproducible. Blender's Basic Human Rigify metarig is an optional authoring workflow if pose editing warrants it. Export the deformation skeleton and baked poses. [Blender Rigify basic workflow](https://docs.blender.org/manual/en/3.4/addons/rigging/rigify/basics.html) · [Blender FBX export options](https://docs.blender.org/api/5.0/bpy.ops.export_scene.html)
2. Target roughly 1.8 m standing height and forward +Z after import. Use named hips, spine, chest, neck, head, clavicles, upper arms, forearms, hands, thighs, shins and feet, with toes where useful. Thumb and grip shapes matter more than full finger articulation for the first pass. Verify the required bone mappings and T-pose in Unity, then play all four existing locomotion clips. [Unity 6.2 Avatar setup](https://docs.unity3d.com/6000.2/Documentation/Manual/ConfiguringtheAvatar.html) · [Unity 6.2 Humanoid retargeting](https://docs.unity3d.com/6000.2/Documentation/Manual/Retargeting.html)
3. Adapt the editor setup to use the new FBX and measured dimensions. Its current Shyr-specific cleanup, bone map and carry bake depend on that mesh. Preserve the single skinned renderer, root Animator, one designated tint slot and `CarryAnchor` expected by the runtime. Refit the carry bake and check grip against the current prop in motion. Build the script-free Windows x64 bundle in Unity 6000.2.6f2. The plugin applies its game-compatible HDRP palette at runtime. [PlayerModelSetup.cs](../../unity/PCBS2CoopModels/Assets/Editor/PlayerModelSetup.cs) · [BuildPlayerBundle.cs](../../unity/PCBS2CoopModels/Assets/Editor/BuildPlayerBundle.cs) · [RemotePlayerView.cs](../../src/PCBS2Coop.Plugin/RemotePlayerView.cs)
4. Review front, side and three-quarter views of idle, walk, PC carry and a bench reach. In two game instances, verify tint and silhouette against workshop lighting, the grip through turn and walk, the feet at rest, and clean recreation on rejoin. A valid Unity Avatar establishes compatibility. This pass establishes whether the model looks good in PCBS2.

## Release evidence

For any acquired art, keep the exact version and official download URL, a checksum, the notice, authors and modifications in the source tree. Include required notices in the mod archive and limit imports to the assets used. The game-asset audit found no suitable native humanoid, and the project excludes game asset copies from the bundle. [Current avatar audit](../playermodel.md#1-audit-what-the-game-already-has)
